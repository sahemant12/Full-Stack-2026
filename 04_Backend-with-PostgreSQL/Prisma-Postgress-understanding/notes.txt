
1. npm install prisma @prisma/client @prisma/adapter-pg pg
2. Initialize Prisma: npx prisma init -> Make prisma folder have "schema.prisma" file AND "prisma.config.ts"
3. Make schema model in schema.prisma
4. npx prisma migrate // This command creates the database tables based on your schema.
5. npx prisma generate // Now run the following command to generate the Prisma Client:
   // GENERATE: src -> generated -> prisma

6. Instantiate Prisma Client: libs -> db.js

7. Now, use DB as instant in anywhere in your project. Similar as model "User" in MongoDB.

8. npx prisma db push/pull // code to the db.
